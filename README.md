advISO Competency Guide
========================

This repository contains the source files for the [advISO Competency Guide](https://adviso-competency-guide.readthedocs.io/en/latest/), which introduces a competency-based framework tailored to bioinformatics.

Built from the [advISO guide template](https://github.com/advISO-project/advISO_guide_template).

## Building locally

```bash
cd docs
pip install -r requirements.txt
make html
```

The built site will be in `docs/_build/html/`. Open `index.html` to preview.
